## 重建页面

`reports/` 保存公开 JSON 与 Markdown。公开数据不包含本机路径、凭据、模型请求 ID 或计费信息。`render.py` 与本机审核服务使用同一 HTML 渲染模板；静态重建不调用模型或外部 API。

运行 `python3 build.py`。GitHub Pages 从 main 分支根目录发布。刷新数据需重新执行本机审核并导出，网页不会自行改变冻结结论。
