外链规则：保留已修复状态

全部非 garvee.com 及其子域的 HTTP(S) 链接加 nofollow，包括 Logo、标题、按钮和重复入口。新窗口同时用 noopener；商业链接按关系补 sponsored。不对图片 src、脚本 src、mailto 或站内锚点加 rel。

可直接复用的域名判断代码
function newsroomLinkRel(href, pageUrl) {
  const u = new URL(href, pageUrl);
  if (!["http:", "https:"].includes(u.protocol)) return undefined;
  const host = u.hostname.toLowerCase();
  const garvee = host === "garvee.com" || host.endsWith(".garvee.com");
  return garvee ? undefined : "nofollow noopener";
}

在服务端输出 a 标签时设置 rel；不要上线后仅用 JS 批量补属性。边界测试：garvee.com / a.garvee.com 为站内；garvee.com.example.org / fakegarvee.com 为外部。

检查项问题具体解决方法
main 嵌套正常渲染存在两个嵌套 main。保留唯一 main；内部纯布局容器改为 div。保持一个 H1。

检查项问题具体解决方法
所属网站页面图谱尚未关联 GARVEE 主站。补 WebSite，CollectionPage.isPartOf 引用它。复用全站 @id；WebSite 站名配置另在根首页部署，新闻室不能替代。主域与 /en canonical 先统一。

页面没有 Schema响应 HTML 和渲染 DOM 均未发现 JSON-LD / Microdata / RDFa。只在 newsroom 路由输出一个原生 script[type="application/ld+json"]；本次完整方案含 8 个实体：原有页面、组织、联系、面包屑、两组列表，再补网站与品牌资源。类型不是越多越好。
实体和字段映射整页是目录，不是一篇新闻；联系人不等于作者。CollectionPage：url/name/inLanguage/about/publisher/mainEntity；Organization：name/url/contactPoint；ContactPoint：email/contactType；BreadcrumbList：Home → Newsroom；WebSite：所属主站；ImageObject：实际 SVG 下载；两个 ItemList：当前快照各 3 条。
列表维护样例为 3＋3，只因当时两个列表各展示 3 篇，不是必须标记或固定数量。需要列表标记时，HTML 与 Schema 共用展示数组；ListItem 的 name/url/position 来自条目，position 为 index + 1。numberOfItems 自动计算；重点报道重复入口不额外计数。
组织身份正式主机/路径尚未统一；预览 Logo 的正式同路径 404。Organization 复用主站稳定 @id；已有根布局实体时合并媒体 contactPoint。pageUrl 用最终规范地址；暂不填 logo，待稳定正式资产 200 后添加。
输出方式客户端注入无法满足首次响应检查。由 Server page/layout 返回原生 script；不经 useEffect、GTM、afterInteractive。序列化时把 < 转义为 \u003c，防 CMS 文本结束 script。
不适用字段媒体报道不等于 GARVEE 身份链接；历史促销不等于当前报价。不加媒体 sameAs、NewsArticle、Product/Offer、评分、虚构作者/日期。新增可见 Home → Newsroom 导航，与 BreadcrumbList 同步。JSON URL 不支持 rel；nofollow 在 HTML a 上设置。
  1. 确定 homeUrl / pageUrl / organizationUrl / organizationId / websiteUrl / websiteId，统一正式 URL 与组织身份。
  2. 在页面显示 Home → Newsroom：Home 链接指向真实首页，Newsroom 用 aria-current=page。需要 ItemList 时才由实际展示数组生成，数量自动计算。
  3. 服务端返回完整图谱：页面、组织、媒体联系、面包屑、网站、品牌资源、两组列表。生产 SVG 尚未上线时省略该资源实体；includeLists=false 可省略报道列表。
